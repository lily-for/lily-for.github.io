# Lily's engineering portfolio

This is a plain HTML, CSS, and JavaScript website that works with GitHub Pages.

## Put it on your existing GitHub site

1. Unzip this folder on your computer.
2. Open https://github.com/lily-for/lily-for.github.io in your browser.
3. Choose **Add file → Upload files**.
4. Drag in `index.html`, `style.css`, `script.js`, and the entire `assets` folder. Upload the contents of this folder, not an extra enclosing folder.
5. Choose **Commit changes**. Your new files replace existing files with the same names. GitHub keeps the previous versions in history.
6. Your existing GitHub Pages site should update after deployment finishes. Check **Actions** to see deployment progress.

If GitHub Pages is not configured, go to **Settings → Pages**, choose **Deploy from a branch**, select your default branch (usually `main`) and **/(root)**, then save.

## How the files work

- `index.html` holds the text and page sections. Browsers use this filename as the website's home page.
- `style.css` controls colors, fonts, spacing, and how the page fits on a phone.
- `script.js` opens full-size photos. Project descriptions and visible photo galleries are in `index.html`.
- `assets/` contains the photos and video. Keep it beside `index.html`.

Open `index.html` on your computer to see a local preview. The font falls back to a standard font when offline.
